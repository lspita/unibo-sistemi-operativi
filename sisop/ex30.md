## Utilizzare semafori per sincronizzare due processi che calcolano la somma di due numeri, garantendo che il processo B inizi solo dopo che il processo A ha calcolato il primo numero

```
Process A {
    V(A)
    while (true) {
        P(A)
        int x = calculate();
        V(B)
    }
}
```

```
Process B {
    while (true) {
        P(B)
        int y = calculate();
        int sum = x + y;
        print(sum);
        V(A)
    }
}
```

## Riscrivere poi il problema per risolverlo coi Monitor.

```
manager = Manager() // globale
```

```
Process A {
    while (true) {
        manager.calc_x()
    }
}
```

```
Process B {
    while (true) {
        manager.calc_y()
        manager.calc_sum()
    }
}
```

```
monitor Manager {
    int x, y;
    boolean first;
    condition restart, x_done, y_done;

    Manager() {
        x = 0
        y = 0
        first = true
    }

    void calc_x() {
        if (first) {
            first = false
        } else {
            restart.wait()
        }
        x = calculate()
        x_done.signal()
    }

    void calc_y() {
        x_done.wait()
        y = calculate()
        y_done.signal()
    }

    void calc_sum() {
        x_done.wait()
        y_done.wait()
        print(x + y)
        restart.signal()
    }
}
```

## Riscrivere poi il problema per risolverlo usando le tecniche di Message Passing.

```
Process A {
    asend(ack, A)
    while (true) {
        areceive(*)
        int x = calculate();
        asend(ack, B)
    }
}
```

```
Process B {
    while (true) {
        areceive(A)
        int y = calculate();
        int sum = x + y;
        print(sum);
        asend(ack, A)
    }
}
```
