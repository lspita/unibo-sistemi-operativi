# Esercizio 29

Completare le seguenti porzioni di codice, utilizzando Semafori e variabili condivise, in modo che i processi stampino "ABECDF" in sequenza.

## Svolgimento

```
Process A {
    V(A)
    while (true) {
        P(A)
        print("A");
        V(B)
        P(A)
        print("E");
        V(C)
    }
}
```

```
Process B {
    while (true) {
        P(B)
        print("B");
        V(A)
        P(B)
        print("F");
        V(A)
    }
}
```

```
Process C {
    while (true) {
        P(C)
        print("C");
        V(D)
    }
}
```

```
Process D {
    while (true) {
        P(D)
        print("D");

    }
```
