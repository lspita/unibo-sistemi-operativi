## Implementare un sistema con 3 processi che utilizzano message passing per calcolare una media di valori. Ogni processo invia il proprio dato agli altri due processi e riceve i dati dagli altri.

```
Process A {
    while (true) {
        x = generateNumber();
        asend(ack, B)
        asend(ack, C)
        areceive(B)
        areceive(C)
        int average = (x + y + z) / 3;
        print(average);
    }
}
```
